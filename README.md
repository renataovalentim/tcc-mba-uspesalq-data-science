# Modelo Preditivo para Identificação da Melhor Condução no Tratamento de Doenças Mentais

Este repositório contém o Trabalho de Conclusão de Curso (TCC) desenvolvido no MBA em Data Science and Analytics (2025).  
O projeto aplica técnicas de **ciência de dados** e **machine learning** para explorar o potencial de modelos preditivos na personalização de tratamentos de saúde mental.

---

## 🎯 Objetivo
Desenvolver e avaliar modelos de machine learning capazes de sugerir combinações terapêuticas (medicação, psicoterapia e exercício físico) para transtornos mentais como:
- Transtorno Depressivo Maior (TDM)  
- Transtorno de Ansiedade Generalizada (TAG)  
- Transtorno Bipolar (TB)  
- Transtorno de Pânico (TP)

---

## 📊 Metodologia
- **Dataset**: [Mental Health Diagnosis and Treatment Monitoring (Kaggle)](https://www.kaggle.com/datasets/uom190346a/mental-health-diagnosis-and-treatment-monitoring)  
- **Análises estatísticas**: ANOVA, Shapiro-Wilk, Qui-Quadrado, Kruskal-Wallis, Spearman  
- **Modelos de machine learning**:  
  - Regressão Logística Multinomial  
  - Random Forest  
  - Gradient Boosting  
- **Ferramentas utilizadas**: Python, scikit-learn, matplotlib, seaborn, Jupyter/Google Colab  

---

## 📈 Resultados
- Acurácia média dos modelos: ~35%  
- Limitações: uso de dados sintéticos sem variáveis críticas (histórico familiar, biomarcadores, dados longitudinais).  
- Proposta futura: coleta padronizada em prontuários eletrônicos, criação de bancos de dados nacionais anonimizados e modelos treinados em populações específicas.
